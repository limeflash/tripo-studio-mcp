# Tripo Studio MCP

**Tripo Studio прямо из Claude Code, за кредиты твоей подписки Studio.**

> [!WARNING]
> Неофициальный проект, никак не связан с Tripo или VAST. Он использует внутренний веб-API сайта studio.tripo3d.ai, который может измениться без предупреждения. Автоматизация может противоречить условиям использования Tripo. Используй на свой риск.

## Зачем

У Tripo два отдельных кошелька. Кредиты Studio идут с веб-подпиской (Pro, Max и т.д.), кредиты API покупаются отдельно для разработчиков. Официальный API, `tripo-cli` и существующие MCP-серверы тратят только кредиты API, а кредиты подписки можно потратить только руками на сайте.

Этот сервер отправляет те же запросы, что и сайт Studio, от имени твоей сессии из браузера. Claude может генерировать, текстурировать, делать ретопологию и скачивать модели за кредиты подписки.

Это переписанный с нуля неофициальный [tripo-studio-plugin](https://github.com/GrinZero/tripo-studio-plugin) (Node, MIT), сделанный так, чтобы нормально работать в Claude Code:

| | tripo-studio-plugin 0.3.12 | **tripo-studio-mcp** |
|---|---|---|
| Запуск | Node 20+ и ~24 МБ бандлов | **один бинарник 7 МБ без зависимостей** |
| Платная задача | подготовка, 60-секундная карточка подтверждения, автоотправка | **один вызов: отправка, цена и остаток кредитов** |
| В Claude Code | карточки падают с `IPC not available (-32603)` | **понятные текстовые ответы** (встроенный виджет в работе) |
| Вход на Windows | чтение cookie браузера не работает (app-bound encryption) | **cookie импортируется один раз** (из файла, значением или из старого плагина) |
| Цены | срок проверки прайса истёк, пишет *unknown* | **датированная таблица цен**, правится без пересборки |
| Дождаться и скачать | отдельные вызовы | **`download_to` в любом платном инструменте** |
| Виды для multiview | четыре пути вручную | **`views_dir`** сам находит `*front*`, `*left*`, `*back*`, `*right*` |

## Быстрый старт

**1. Бинарник.** Скачай со страницы [Releases](../../releases) или собери:

```bash
go build -o tripo-studio-mcp.exe .
```

**2. Подключи к Claude Code.** Команда подключает сервер к текущему проекту; с `-s user` он будет во всех проектах.

```bash
claude mcp add tripo-studio -- C:/Tools/tripo-studio-mcp.exe
```

**3. Войди один раз.** В Chrome или Edge, залогиненном на [studio.tripo3d.ai](https://studio.tripo3d.ai): DevTools → Application → Cookies, скопируй значение `ory_kratos_session` в текстовый файл. Потом попроси Claude:

> Импортируй сессию Tripo из `C:/Users/me/tripo-cookie.txt`

Cookie проверяется на сервере Tripo, сохраняется в `%LOCALAPPDATA%\TripoStudioMCP\session.json` и нигде не выводится. Сессия живёт около 30 дней. Файл с cookie после импорта удали.

**4. Сделай что-нибудь.**

> Сделай Smart Mesh P1 по видам из `./parts/arm/inputs`, 19 500 полигонов, сохрани в `./parts/arm/mesh.glb`, потом затекстурь в 2K по тем же видам и сохрани `textured.glb`.

## Инструменты

| Инструмент | Кредиты | Что делает |
|---|---:|---|
| `tripo_generate_model` | **35** P1 · **100** P2 · от 15 H3.1 | Модель по одной картинке или по multiview (front и хотя бы один из left/back/right) |
| `tripo_texture` | **10** 2K · **20** 4K · **30** 8K | Текстура для готовой модели без изменения геометрии |
| `tripo_remesh` | **5 / 10** обычный · **35 / 40** Smart Poly | Ретопология (треугольники / квады) |
| `tripo_segment` | **40** | Разбиение модели на смысловые части |
| `tripo_wait` | бесплатно | Проверить или дождаться задачи, при желании скачать результат |
| `tripo_download` | бесплатно | Сохранить модель: текущую, прошлую версию или экспорт в glb/fbx/obj |
| `tripo_list_projects`, `tripo_project` | бесплатно | Список моделей и состояние модели (текстура, квады, Smart Mesh, риг) |
| `tripo_balance` | бесплатно | Кредиты, тариф, бесплатные лимиты |
| `tripo_auth_import`, `tripo_auth_status` | бесплатно | Сохранить и проверить сессию |
| `tripo_upload_image` | бесплатно | Загрузить картинку и прогнать проверку контента Tripo |

Любой платный инструмент принимает:

- **`dry_run: true`** — проверить входные данные и показать цену с балансом; ничего не загружается и не списывается.
- **`download_to: "путь"`** — дождаться задачи и сохранить модель в том же вызове.

По умолчанию выбраны самые дешёвые разумные варианты: Smart Mesh **P1**, треугольники, **private**, текстура 2K, стандартная геометрия, без PBR.

## Безопасность платных вызовов

- Платный инструмент отправляет задачу сразу. Сервер просит Claude сначала получить твоё согласие на цену, а `dry_run` эту цену показывает.
- Если Tripo отказал (например, код 2010 — не хватает кредитов), ошибка начинается с *not submitted, nothing charged*: ничего не списано.
- Если сеть оборвалась после отправки, это *outcome unknown*. Платные запросы **никогда не повторяются автоматически**: сначала проверь `tripo_list_projects`.
- Аргументы проверяются строго: опечатка в названии параметра даёт ошибку, а не молча игнорируется.

## Цены

Цены лежат в [`prices.json`](prices.json): по ключам цен самого Studio, с датой проверки. Чтобы поменять цену без пересборки, положи переопределение в `%LOCALAPPDATA%\TripoStudioMCP\prices.json`:

```json
{ "updated": "2026-11-01", "credits": { "GenerateBaseNexus": 40 } }
```

Файл перечитывается при каждом вызове.

## Планы

- [ ] **Полный порт** всех 68 инструментов плагина: генерация картинок и multiview, текстовые и пакетные входы, варианты P2, импорт моделей, PBR, апскейл текстур и Magic Brush, Smart UV, достройка частей, риг, анимация и motion, локальная правка в Blender, группы ассетов, история задач.
- [ ] **Встроенный виджет результата** в Claude: 3D-превью, миниатюры входов, цена и прогресс. Всё нужное он получает в результате вызова и не зависит от обратных вызовов инструментов через хост — на них ломаются карточки оригинала.
- [ ] Готовые сборки для Windows, macOS и Linux.
